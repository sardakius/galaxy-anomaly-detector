# An Analysis of Several Autoencoder Configurations to Identify Galaxy Mergers via Anomaly Detection
The Euclid Quick Data Release recently released a catalog of galaxy images from the mission and developed a Convolutional Neural Network (CNN) to identify galaxy mergers. However, many of the galaxies were not distinctly identified. In this paper, I aim to classify these remaining "unknown" galaxies using Autoencoders designed for Anomaly Detection. I evaluate configurations of several different models, image denoising methods, and loss functions using the AUC-PR, AUC-ROC, and F1-score metrics. I found that using a Contractive Autoencoder, VisuShrink wavelet denoising, and a Gaussian-weighted $\chi^{2}$-Loss Function provided the largest AUC-PR Score. This specific configuration was used to classify 2763 of the unknown galaxies.
